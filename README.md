# Calculator Test App

A clean, dark-theme calculator made with React Native and Expo.

## Features
- Addition, subtraction, multiplication, and division
- Percentage and sign toggle
- Decimal input and backspace
- Clear button
- Expression display
- Responsive layout for phones
- Offline calculations

## Run
```bash
npm install
npx expo start
```

Open in Expo Go or build using an Expo-compatible workflow.

## Test project
Created as a starter/test app for experimenting with AI app builders such as Newly.app.
